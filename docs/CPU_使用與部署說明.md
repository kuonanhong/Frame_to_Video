# FRAME CPU 圖片轉短影片：使用與部署

版本：2026-10-07。這份指南適用於本套件新增的 `edge/` 本機工具；舊版 `dist/` AI 工作室與 `backend/` 的說明見 `docs/CLASSIC_README.md`。

## 1. 這個版本免費到什麼程度

- 圖片辨識與照片動畫在使用者的瀏覽器執行，不需要雲端推論帳號、付費 API、CUDA 或共用運算伺服器。
- 使用者的圖片不會因辨識、預覽或匯出而傳送到伺服器。網站仍會下載 JavaScript、語系、示例及辨識模型；這是下載程式，並非上傳照片。
- COCO-SSD 是神經網路物件偵測模型，所以辨識步驟有使用非生成式 AI。動畫步驟是幾何與粒子規則，沒有使用 Diffusion、影片 Transformer 或大型語言模型。
- 「不需要 GPU 推論」不表示整個瀏覽器一定完全不用 GPU。模型適配器明確使用 TensorFlow.js CPU 後端；瀏覽器的畫面合成與影片編碼仍可能使用系統硬體加速。
- 免費也不代表沒有下載流量、裝置耗電或網站託管限制。多人各自在自己的裝置運算，避免集中式推論佇列；不能因此保證十萬人同時開啟網站而不遇到 CDN、頻寬或服務限額。

## 2. 在電腦本機開啟

快速方式：直接開啟套件根目錄的 `FRAME_CPU_Studio.html`。這個CPU單檔版內嵌程式、語系、模型與Worker，可雙擊使用，與原版雲端AI單檔的能力不同。單檔較大，首次開啟與模型初始化仍需時間；若某瀏覽器禁止本機Worker或錄影，請用下方HTTP方式。

建議使用本機 HTTP 網站，避免 `file://` 對模型載入、模組與 Worker 的限制。解壓縮後，在包含 `edge/`、`dist/`、`docs/` 的 `FRAME_AI_Studio` 資料夾執行：

```bash
python3 -m http.server 8080
```

Windows 已安裝 Python 時可使用：

```powershell
py -m http.server 8080
```

然後以現代瀏覽器開啟：

- 新增的 CPU 工具：`http://localhost:8080/`，或 `http://localhost:8080/edge/`
- 原版生成式 AI 工作室：`http://localhost:8080/dist/`
- 操作文件：`http://localhost:8080/docs/CPU_使用與部署說明.md`

停止本機網站：回到終端機按 `Ctrl+C`。

同一部電腦使用 `localhost` 不需要公開網站帳號。讓同一區域網路手機開啟時，須使用電腦的區域網路位址、允許防火牆相應連線；部分 API 對不安全的 HTTP 來源有限制，因此手機正式使用建議直接開 GitHub Pages 的 HTTPS 網址。

## 3. 操作流程

1. 選擇 JPG、PNG 或 WebP 圖片，或按「使用示例」。先使用較小照片，以降低首次解碼與記憶體負擔。
2. 按「辨識物件」。辨識只執行一次，並列出模型找到的常見物件、方框與信心分數；不是逐幀跑模型。
3. 檢查方框是否符合照片。框錯、框太大或沒有辨識到的區域，請刪除或手動補畫。
4. 水面、樹木、雲朵等自然區域請選擇相應類型，再按「新增區域」，在原圖上拖曳方框。手機／平板可用手指畫框。
5. 輸入支援的動態提示詞，或按效果按鈕。例如：
   - 「鏡頭慢慢拉近」
   - 「樹木搖擺」（需先畫出樹木區域）
   - 「水面波紋」（需先畫出水面區域）
   - 「小船漂浮」（需有船的辨識方框或合適區域）
   - `zoom in`、`pan left`、`sway`、`water ripple`、`snow`
6. 按「套用提示詞」，檢查計畫摘要及尚未支援的描述。這是有限關鍵字規則，不理解任意自然語言指令；切換介面語言也不代表所有語言提示詞都已完整支援。找不到規則時可按效果按鈕，按鈕使用已知內部規則。
7. 先選 480p、18 fps、4 秒，按「預覽」。裝置順暢再試 720p 或較長片段。
8. 按「匯出影片」，保持分頁在前景並等待完成。完成後按「下載」，或用「儲存單幀」下載圖片。

影片是無聲短片，不會憑空為照片加上人物說話、走路或動物飛翔。選取區域內的小幅變形是視覺效果，不是已恢復物件的三維姿態。

## 4. 畫面比例與影片格式

橫式 16:9、直式 9:16 及正方形 1:1 輸出會保持來源圖片的比例，再裁切填滿畫面，不會把橫式照片直接拉伸成直式。鏡頭推拉或平移時可能裁去邊緣；重要人物與文字請保留在安全位置。

瀏覽器會依 `MediaRecorder.isTypeSupported()` 選擇實際支援的容器與編碼：

- 部分瀏覽器輸出 WebM；有些裝置可輸出 MP4。
- 不保證所有 Safari、Chrome、Firefox 或手機版本有相同格式與錄製能力。
- 下載副檔名應與實際 MIME 類型一致；將 `.webm` 改名成 `.mp4` 不會完成轉檔。
- 若瀏覽器無法錄影，可先存單幀，或改用較新的瀏覽器。畫面能預覽不代表影片編碼器一定可用。
- 舊版 iPod、記憶體很小的裝置與過時瀏覽器沒有相容性保證。

本機若需要轉成常見 MP4，且有安裝 FFmpeg，可用軟體 H.264 編碼：

```bash
ffmpeg -i input.webm -c:v libx264 -pix_fmt yuv420p -an output.mp4
```

上面是可選的本機轉檔，並非網頁必需套件；轉檔耗時依裝置與影片大小決定。

## 5. 部署到 GitHub Pages

新 CPU 工具可以作為靜態網站提供，無需部署 `backend/`。為保留本套件內部連結，建議上傳完整專案的網站檔案與文件，並保留以下相對位置：

```
FRAME_AI_Studio/
  index.html
  FRAME_CPU_Studio.html
  edge/
    index.html
    app.bundle.js
    style.css
    locales.json
    detector-worker.js
    motion-worker.bundle.js
    model/
      coco-ssd-lite/model.json
      coco-ssd-lite/group1-shard1of5
      coco-ssd-lite/group1-shard2of5
      coco-ssd-lite/group1-shard3of5
      coco-ssd-lite/group1-shard4of5
      coco-ssd-lite/group1-shard5of5
  dist/
    index.html
    assets/
  docs/
```

實際套件會包含更多原始碼、授權與測試檔；上面列的是重要執行關係。不要只上傳一個 `edge/index.html` 而遺漏模型權重、Worker 或語系。也不要把專案 `node_modules/` 或 Python 虛擬環境上傳到 Pages。

步驟：

1. 在 GitHub 儲存庫加入套件內容，保留資料夾結構。
2. 進入儲存庫 Settings → Pages，使用既有 Pages 方式，或選「Deploy from a branch」，選擇 `main` 分支與 `/(root)`。
3. 等待部署完成，開啟 `https://使用者.github.io/儲存庫名稱/`；`/edge/`也是同一CPU工具的入口。
4. 上傳照片，檢查模型與 Worker 是否載入成功，再測試預覽、影片下載及語言切換。
5. 更新時要同步更新 HTML、JavaScript、語系與模型檔案；遇到舊快取，可強制重新載入或用無痕視窗確認。

線上建議使用多檔版本，辨識模型到按下辨識時才載入；單檔HTML約24.6 MiB，適合本機離線使用，會一次載入較多文字與權重。若GitHub網頁上傳限制拒收大單檔，可使用GitHub Desktop推送，或不上傳這個可選單檔，保留多檔版的根入口與整個edge資料夾即可。

若放在聰動網站的子資料夾，可讓主頁以一般超連結指向這個 `edge/` 入口。不需要隱藏點擊、觀看影片解鎖或其他互動門檻。

GitHub Pages 只提供靜態檔案。原版 `dist/` 若選雲端或自架生成式模型，依然需要其模型服務；新增的 `edge/` CPU 功能則不依賴這些服務。

## 6. 多語與多人使用

共用介面提供22種語言：繁體中文、簡體中文、英文、日文、韓文、阿拉伯文、馬來文、泰文、越南文、印尼文、菲律賓文、德文、波蘭文、捷克文、葡萄牙文、芬蘭文、瑞典文、俄文、法文、西班牙文、義大利文、印地文。阿拉伯文使用由右至左版面。

這些是工具核心介面翻譯，不是所有國家語言或原網站全文翻譯。譯文由 AI 輔助，尚未經各語母語編輯審校。COCO模型類別標籤可能保留英文；規則提示詞支援範圍請以演算法文件與摘要提示為準。

每位使用者只有自己分頁的圖片、模型記憶體與動畫工作，不會互相覆蓋。大量訪客仍共同下載網站與模型；容量規劃、CDN快取與實際負載測試另需處理，不能把本機運算架構等同於無限制的免費網站流量。

## 7. 問題排查

| 現象 | 先檢查 |
|---|---|
| 模型載入失敗 | 是否使用HTTP／HTTPS、是否漏上傳五個權重分片、相對路徑與大小寫是否一致。 |
| 找不到照片中的樹／水／天空 | 模型不是自然景物分割器，請用手動區域。 |
| 提示詞沒有作用 | 查看計畫摘要；以支援詞或效果按鈕設定，並確認有對應區域。 |
| 方框中的背景也跟著動 | 方框是近似遮罩；縮小手動區域並用小幅效果，不能期待精細輪廓分離。 |
| 預覽很慢 | 改480p、較低幀率、較短秒數及較少區域；關閉多餘分頁。 |
| 影片缺幀／時長不一致 | 錄製依實際裝置計算與編碼速度，先降設定並保持分頁前景。 |
| 影片格式不能播放 | 使用支援該格式的播放器或本機FFmpeg轉檔，不要只改副檔名。 |
