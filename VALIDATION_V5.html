Inpainting 設定 20 步與 strength=0.99，實際回呼為 19 次；報告保留設定與觀察值。

六項已寫入程式但尚未真實生成驗證

LivePortrait、ControlNet、MultiDiffusion、FLUX.2 Klein、LTX-Video、CogVideoX 均有安裝器、真正的模型呼叫、工作佇列與輸出回流介面。本次未逐一下載它們的大型權重並完成生成。子程序模擬測試不能替代模型推論測試。

本版 LivePortrait 與三個現代大型模型環境阻擋 Intel macOS 原生安裝。ControlNet／MultiDiffusion 採固定舊版依賴作為 Intel Mac 候選，未完成 Mac 實機驗證。LivePortrait 的 CPU 路徑仍為實驗性。

  • 43 項 Node 測試：運鏡、時間軸、視覺狀態、語系與專家介面規則。
  • 30 語系各有 256 個原有介面翻譯與 10 個新增專家文字；字串覆蓋檢查不是模型語言能力證明。
  • 5 項專家介面 DOM 檢查：公網站／file 不探測本機服務、草稿套用、驅動影片要求、未安裝模型阻擋。
  • 4 個完整入口 DOM 啟動檢查：file、localhost 根目錄、story 別名與 GitHub Pages 子路徑。使用 Canvas stub，並非真實瀏覽器影片匯出測試。
  • 16 項 native CPU 單元／HTTP／介面測試；Linux 安裝、啟動與首頁讀取實測通過。

  • 19 項本機 bare Git 整合測試；未執行使用者 GitHub 的真實 SSH 推送。
  • 25 個原有瀏覽器模型實體資產／分塊已核對 SHA-256，所有離線資源路徑與大小已檢查。
