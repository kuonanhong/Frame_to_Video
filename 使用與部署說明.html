1　開啟方式與本次按鈕修正

原本 Studio 3 的入口是外部 ES module。本機雙擊使用 file://，瀏覽器會限制此類程式載入，導致加入素材、示範、儲存等事件沒有安裝。GitHub Pages 使用 HTTPS，即使讀取同名 index.html，執行環境仍不同。

方式v4 行為何時使用
雙擊 index.html一般 JavaScript 打包入口；可操作基本分鏡、素材匯入、示範、專案、圖層、照片效果與瀏覽器支援的輸出。AI 配音／物件模型與離線快取按鈕明確停用。快速試用；必須先解壓縮完整資料夾。
localhost HTTP完整瀏覽器工作台、內附 WASM AI 敘事與語音模型、物件辨識。本機開發與完整使用。
GitHub Pages HTTPS訪客直接開啟，不需安裝 Python。模型在訪客的裝置執行。公開網站。
本機 CPU 專家伺服器安裝 Python 套件並下載選配模型後，可執行真正的圖片生成／編輯。桌機／筆電；不是 Pages 後端，也不是手機純瀏覽器功能。

建議在終端機執行：

cd "/你的解壓縮路徑/FRAME_AI_Studio"
python3 serve.py

開啟 http://127.0.0.1:8000/；原本的 python3 -m http.server 8080 --bind 127.0.0.1 也可以，網址要對應 8080。Windows 若只有 py，使用 py -3 serve.py。也可使用 Start_Mac.command、Start_Linux.sh、Start_Windows.bat。Mac 因解壓縮失去執行權限時，用上述 python3 指令即可。

需要本機圖片專家時，先照 CPU 安裝指南 安裝，再使用 python native_cpu/server.py --port 8787，開啟 http://127.0.0.1:8787/。不要同時把兩個伺服器的網址混用。

2　先完成一部能正常輸出的影片

  1. 按「載入示範」，或按「加入圖片／影片」，也可將檔案拖到素材區。最多 20 個分鏡。
  2. 選取分鏡，設定秒數；「敘事／旁白」是要說出的文字，「字幕」是畫面文字。
  3. 在 localhost 或 Pages 選中文／英文聲庫，按「生成可匯出配音」。系統語音試聽無法可靠錄進影片，請使用生成音訊、上傳錄音或麥克風錄音。
  4. 設定照片動態、設計圖層、轉場、亮度、色彩與配樂。
  5. 先用 360p / 12fps 試輸出；電腦再提高到 540p / 24fps 或 720p。按「免費匯出影片」，保持分頁在前景，完成後按下載。
  6. 「儲存專案」下載包含照片／音訊／圖層的 JSON；用「開啟專案」繼續編輯。不要只依賴瀏覽器快取保留自己的素材。

輸出為裝置支援的 MP4 或 WebM；Auto 優先選可識別的 H.264 MP4，否則使用 WebM。不能保證所有平台的 MP4 都是相同編碼器。10 分鐘是軟體上限，不代表低記憶體手機一定能承受。

3　把動態提示與旁白分開

新面板「照片動態與設計」有獨立的影像效果提示。可輸入「水面波紋，鏡頭慢慢拉近」，按套用，再檢查顯示的效果與運鏡。水面／搖動請用滑鼠或手指框選區域。也可以直接選擇水波、搖動、雨、雪，不必依賴文字解析。

文字解析仍是有限關鍵字規則，並非能理解所有語言與否定句的語言模型。遇到「大笑、讀書、換衣服」等不支援動作會顯示提示，不會把它們默默當作已完成的動作。旁白欄的文字不會自动改變人物姿態。

舊的 FRAME_CPU_Studio.html 使用 COCO-SSD SSDLite MobileNet V2（約 18.6 MB，TensorFlow.js CPU）偵測 80 類物件；動畫是程式化像素變形。它沒有內附生成式影片權重。本版已把主要風景動態效果整合到主頁，並保留原版供對照。

4　圖片設計、家具與全景

  • 圖層設計：添加原創向量沙發、植物、燈、鳥、魚；調整位置、尺寸、角度、透明度、顏色與前後順序。每幕最多 8 層，可匯入自己的透明 PNG。這是平面合成，沒有自動遮擋、CAD 尺寸或房間幾何。
  • 生成新設計：使用選配本機圖片專家，可嘗試髮型、服装、妝容、天氣與家具修改。遮罩補畫需要將要修改的部位塗白。生成結果另加一幕，保留原圖；細節與人物身份不保證一致。
  • PNG：可儲存合成圖片。影片輸出亦包含設計圖層；SRT 字幕不包含圖層。
  • 360°：只檢視已存在的 2:1 等距柱狀全景照片，調整觀看方向／掃視。普通照片不會推測出背面的真實空間；沒有把一張民宿照片重建成真實 3D CAD。

本機 CPU 生成程式SD-Turbo、InstructPix2Pix、SD1.5 Inpainting 三種圖片專家附程式與下載／驗證工具；大型權重及 Python 二進位依賴另外安裝，不在 ZIP。

較大型模型不能以「TensorFlow 有 CPU 版」推論成「手機瀏覽器就能流暢生影片」。模型算子、記憶體、序列長度與編碼器都影響可行性。多個專家依序載入會節省同時佔用的記憶體，但不會消除每個模型的計算量。

內附神經模型需先在 HTTP/HTTPS 載入；按「準備離線使用」保存瀏覽器快取後才可斷線。瀏覽器可能清除快取；原始完整資料夾應另行保存。本機 CPU 專家先下載依賴與模型，之後以 local_files_only 與 CPU float32 執行。免費使用仍需遵守各模型授權，不能將所有權重統稱為 MIT 或保證所有商業用途。

其他候選包含 Qwen、LivePortrait、ControlNet、MultiDiffusion、FLUX.2-klein、LTX-Video、CogVideoX，詳見模型查核表；列入比較不代表本版已安裝或整合。

6　多語系與裝置

核心介面擴充至 28 語系，依瀏覽器語言偏好自動選擇，並保留手動選擇。繁簡中文依 zh-TW／zh-HK／zh-Hant 與 zh-CN／zh-SG／zh-Hans 等設定區分；語言偏好不是所在地的精確定位。Google 地圖只在使用者按鈕並同意定位後開啟，無需地圖 API Key。

手機／平板提供觸控區域框選、圖層控制與較低輸出預設。記憶體與硬體資訊只是瀏覽器提示，不是完整性能檢測。語系擴充不會擴充語音模型語言；模型／系統診斷可能仍有英文。

7　GitHub 上傳與更新

完整 PAT 與部署教學包含申請精細權限 Token、Mac／Windows／Linux 指令、初次上傳、後續增量更新與常見錯誤。將解壓縮後的 內容 放到網站儲存庫根目錄：index.html、story/、edge/、dist/ 與 .nojekyll 需一同存在。

內附權重以約 40 MiB 分片，普通 Git 可追蹤；不要改用 Git LFS 給 Pages 載入。git pull 是取回更新，git push 才是上傳。Token 只輸入 Git 憑證提示，不要放到 HTML、程式、網址或公開儲存庫。本版未替您發佈或改動 GitHub 帳號。

本版同時提供小型 Update ZIP：只適用於先前完整 Story 3.0 資料夾。先備份，再合併覆蓋；不可單獨作為完整程式，亦不適用只含舊 CPU 頁面的資料夾。若不確定版本，使用完整包。

8　驗證範圍與已知限制

本輪核查了實際上傳截圖、MP4、WebM 與 CPU ZIP；Story 新上傳副本未能讀取，因此以先前交付並取回的 Story 3.0 原始包繼續修改。三個 ChatGPT 網址未能直接讀取。本輪測試結果與範圍列於 驗證報告，不將 DOM 模擬或程式單元測試描述為真機瀏覽器測試。

本輪已完成一次 Linux 上的 SD-Turbo 真實 CPU 推論：512×288、3 個有效去噪步、含載入約 15.95 秒，程序峰值記憶體約 5.70 GiB。其他兩個圖片專家仍未做真實權重推論；沒有在您的 Intel Mac、Safari、iPhone 或 Android 真機實测，也沒有 GitHub 外部部署。沒有證據支持「最佳模型」「最準生成」「所有裝置零延遲」。如人物動作生成是核心驗收條件，目前這部分仍未完成。
