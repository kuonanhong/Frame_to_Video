# FRAME Story Studio：能力、模型及邊界

版本日期：2026-10-09。這版將「圖片／影片分鏡、故事文字、可匯出旁白與基本後製」放進可發布到 GitHub Pages 的靜態工作台。它提供本機生成式文字與語音；影片畫面則以既有素材、幾何運鏡、轉場及濾鏡構成。

## 實際提供什麼

| 功能 | 本版做法 | 實際範圍 |
|---|---|---|
| 分鏡圖片／影片 | 使用者加入素材，調整順序、複製／刪除分鏡與秒數 | 影片必須為瀏覽器可解碼的格式；記憶體與素材大小仍有限。 |
| 常見物件辨識 | 原套件 COCO-SSD SSDLite MobileNet V2、TensorFlow.js CPU | 80 類常見物件的矩形方框；不是所有物件、精細分割或照片語意理解。 |
| 生成式敘事 | SmolLM2-135M-Instruct，量化 ONNX，Transformers.js／ONNX Runtime WASM CPU | 以你輸入的描述及物件標籤為文字條件；小模型主要適合英語，非視覺問答模型。 |
| 可匯出神經語音 | Piper 中文／英語小聲庫，本機 WASM CPU 推論 | 本包附 3 個聲庫，並非所有語言、任意年齡或人格聲音。 |
| 自己／別人的聲音檔 | 上傳錄音或授權麥克風錄音，直接作旁白音軌 | 不做聲音克隆、音色訓練、語音換臉或自動模仿人物。 |
| 系統語音試聽 | Web Speech API 列出裝置提供的聲音 | 僅試聽；不保證離線，也不當作已可合成進影片的 PCM 音軌。 |
| 照片運鏡 | 靜止、推近、拉遠、平移，保持比例再裁切 | 不是人物真的走路、張嘴或物件真實三維運動。 |
| 影片裁切 | 分鏡的起始／結束時間 | 基本剪輯；不是完整的多軌專業剪輯系統。 |
| 轉場 | 直接切換、淡入淡出、滑動 | 本版的有限預設效果。 |
| 打光／影像後製 | 亮度、對比、飽和度、暖色光濾鏡 | 對現有像素調整，不能恢復被遮住的表面或重新計算真實三維光照。 |
| 音訊 | 逐分鏡旁白、配樂、音量調整及原創背景音樂 | 素材可解碼時可混入匯出影片；錄音可能因瀏覽器而不同。 |
| 字幕 | 人工／敘事文字字幕、燒入畫面及 SRT 下載 | 不包含通用離線自動語音辨識／翻譯模型。 |
| 多語 | 22 語核心介面，瀏覽器偏好與手動切換 | 介面語系、敘事模型語系與配音模型語系分開，不能互相等同。 |
| 地圖 | 明確按鈕授權定位後開 Google Maps 連結 | 不需要 Maps API key，不用位置判斷語言；地圖不是離線功能。 |
| 跨平台 | 現代瀏覽器、響應式版面、觸控及能力檢查 | macOS、Windows、Linux、Android、iPhone／iPad 的能力取決於瀏覽器；不能保證所有舊裝置或全部編碼格式。 |
| 多人使用 | 每位訪客各自在自己的瀏覽器處理素材 | 沒有共用推論伺服器，但模型下載仍受託管容量與頻寬限制。 |
| 免費 | 已附程式與模型在裝置上執行，不必買推論 API | 裝置、電力、儲存、網路與網站流量不是無限供應。 |

## 附帶的生成式小模型

敘事模型使用 `onnx-community/SmolLM2-135M-Instruct-ONNX-MHA` 的固定版本 `5b6682c7c9df18f004bfb7e635cba3f3d98537d8`，q8 主權重約 131.11 MiB（137,479,710 bytes）。它是小型文字模型，模型規模限制了長故事、推理、事實正確性及中文能力；本版沒有宣稱其為所有模型中「最準」或最先進。

三個 Piper 聲庫取自固定來源版本 `c10ece1aade47bb51c153c893d14e5bf8e5b7117`：

| 聲庫 | 語言 | 單一 ONNX 權重 |
|---|---|---|
| `zh_CN-huayan-medium` | 中文普通話 | 63,201,294 bytes |
| `en_US-amy-low` | 美式英語 | 63,104,526 bytes |
| `en_GB-alan-low` | 英式英語 | 63,104,526 bytes |

中文配音會作文字前處理，字幕仍可保留原本的繁體中文。這不代表模型能正確讀出所有臺灣人名、臺語、方言、專有名詞或中英夾雜詞；需要先聽過並修正文字。

敘事與神經語音權重合計約 326.89 MB，另有 tokenizer、音素處理器、推論執行程式與 WASM。下載檔案大小不是執行時記憶體：模型初始化、ONNX 中間 tensor、KV cache、錄音與素材解碼可能再消耗數倍記憶體。手機應把敘事推論視為可選功能，不要只因權重檔很小就推定所有手機都流暢。

程式以 WASM CPU 執行模型，不需要 CUDA 或 WebGPU 推論。本包使用模型來源清單、固定版本、SHA-256 校驗及專用分片載入器；大型權重以可上傳的一般 Git 檔案分片保存，由載入器還原完整二進位後交給推論引擎。不能任意切開另一個 ONNX 檔、漏傳一片，或改成 Git LFS 指標就期待其正常推論。

實際隨附版本、檔名及校驗值見 `story/models/manifest.json`；聲庫的原始 model card 位於 `story/models/piper/`，依賴程式的授權與對應來源保留於 `story/vendor/`。Piper 聲庫儲存庫雖標示 MIT，`zh_CN-huayan-medium` 的 model card 對訓練資料集授權標示為 `Unknown`；不能因此推導所有模型與資料都已獲完整商用授權。音素處理程式另包含 GPL 授權元件。本包保留相應 model card、來源、授權文字及通知，不把全部第三方元件統一宣稱為本專案 MIT。

## 為何不是完整的生成式圖片轉影片

生成新影格的通用 I2V diffusion／video transformer，通常需要更大的模型、更高記憶體和大量推論計算。把它放進靜態網站，不能使使用者的 CPU 自動具有 GPU 的速度。即使某些模型理論上可使用 CPU，也不能據此保證手機即時、低耗電、畫面最準、免費且流暢。

本版的生成式 AI 工作是：**生成故事文字，以及將文字生成語音音訊**。影片是以你供應的照片與影片為素材，在時間軸上作運鏡、裁切、轉場及調色，再疊合旁白、配樂與字幕。單張照片不會憑空獲得可信的下一秒人物姿態；沒有人物口型同步、任意物件新增／移除、背景補畫或人體動作生成。

若日後接入真正 I2V 模型，必須另行驗證其模型授權、CPU／瀏覽器支援、記憶體、效能與輸出品質，並清楚區分本機推論和外部服務。原套件的 `backend/` Python 模型適配器不會由 GitHub Pages 執行。

## 不等同於 CapCut／威力導演

這是免費的短故事工作台，包含上述基本後製。沒有宣稱完整複製商用軟體：不包括完整多軌嵌套時間軸、曲線關鍵影格、動作追蹤、精細遮罩、色度去背、專業色彩管理、所有特效、完整字幕辨識、多機位同步、所有影音編碼器或雲端協作。

用已提供的基本工具即可做出「分鏡照片／短影片 → 故事 → 配音 → 配樂 → 字幕 → 匯出」。需要完整專業剪輯時，可把生成的 WAV、SRT 與影片匯入你選擇的編輯器繼續處理。

## 語言、離線與私隱

核心介面翻譯 22 語，不代表敘事模型精通 22 語、也不代表附帶 22 種神經 TTS 模型。英語敘事生成後可自行改為其他語言；沒有對應配音聲庫時，使用錄音或上傳該語言旁白。

介面依 `navigator.languages` 的使用者語言偏好選擇；這不是所在國家的可靠偵測。手動語系保存在此瀏覽器，不能把每一位瀏覽者的國籍、地址或語言當作同一件事。位置只在明確地圖操作後要求授權，製片流程無須定位。

使用者素材、文字與錄音由本機處理，不因敘事、配音或匯出而上傳到模型伺服器。初次仍需下載網站與模型；線上供應靜態檔案不代表遠端進行推論。第一次準備快取完成之後，相關功能可離線使用；瀏覽器仍可能回收或清除快取。

瀏覽器 Canvas 合成、MediaRecorder 編碼與作業系統媒體處理可能使用硬體加速。**「不要求 GPU 模型推論」不能等同「所有繪圖／編碼一定由 CPU 軟體執行」**。嚴格要求軟體 CPU 編碼時，請另外在本機使用 FFmpeg `libx264` 等已驗證的軟體編碼器。

## 驗收重點

交付包的測試紀錄描述本次真正驗證的範圍。上線前仍應在你的 Mac、目標 Android 手機和 iPhone／iPad 上各測一次：初次載入、斷線重開、分鏡編輯、語音生成、錄音授權、配樂混音、字幕、匯出格式及長片記憶體。不要把單一桌面瀏覽器測試寫成所有平台都已實測，更不能把本機推論架構視為十萬人並發負載驗證。
