1．解壓縮與開啟

解壓縮後找到含 index.html、story/、native_cpu/、advanced_service/ 的 FRAME_AI_Studio。請保留整個資料夾。

直接雙擊 index.html 可以使用基本剪輯。瀏覽器模型、離線快取及專家服務請用 localhost 或 HTTPS。基本 HTTP 模式：

cd "/你的解壓縮路徑/FRAME_AI_Studio"
python3 serve.py

也可使用包內的 Start_Mac.command、Start_Linux.sh、Start_Windows.bat。依終端機顯示的網址開啟；基本模式不會啟動進階模型。

2．修復版 CPU 改圖：SD-Turbo、Pix2Pix、Inpainting

建議先安裝 Python 3.11。Mac／Linux 使用：

cd "/你的解壓縮路徑/FRAME_AI_Studio"
python3.11 native_cpu/setup_native.py --model sd-turbo --model instruct-pix2pix --model sd-inpaint
bash advanced_service/Launch_Mac.command

Linux 也可用 bash advanced_service/Launch_Linux.sh。Windows PowerShell：

cd "C:\你的解壓縮路徑\FRAME_AI_Studio"
py -3.11 native_cpu/setup_native.py --model sd-turbo --model instruct-pix2pix --model sd-inpaint
.\advanced_service\Launch_Windows.bat

這會建立 .venv-native、安裝固定版本套件，並下載所選模型。第一次需要網路、數 GB 磁碟及等待時間；之後已安裝模型可離線使用。若 Python 指令找不到，先安裝 Python 3.11 並重開終端機。Intel Mac 使用 PyTorch 2.2.2；Linux／Windows 使用 CPU 套件。沒有宣稱已在每種作業系統完成實機測試。

  1. 開啟 http://127.0.0.1:8787/。
  2. 加入圖片，選取分鏡，展開「本機 CPU 生成式改圖」，按檢查服務。
  3. 選模型、輸入提示詞。Inpainting 要先塗白需要更動的區域。
  4. 生成成功後，圖片會新增成分鏡，原圖仍保留。

3．新增七個專家模型

每個專家使用自己的 Python 環境，互不覆蓋套件。只安裝您需要的模型；不要一次下載全部。以 Qwen 中文敘事為例：

cd "/你的解壓縮路徑/FRAME_AI_Studio"
python3.11 advanced_service/install.py qwen-text --download
bash advanced_service/Launch_Mac.command

Windows 將第一個指令的 python3.11 改為 py -3.11，啟動使用 advanced_service\Launch_Windows.bat。其餘專家以相同安裝指令替換模型 ID：

模型 ID操作／結果須知
qwen-text文字 → 敘事草稿；檢查後套用字幕與旁白不會看圖；圖片內容需自己寫成文字
liveportrait人像＋10 秒內驅動影片 → 人像動畫CPU 實驗路徑；本版 Intel Mac 安裝不支援；另需 FFmpeg／FFprobe
controlnet-canny選取圖片＋提示詞 → 依輪廓生成圖片不是精密 CAD，也不保證人物與物件完全不變
multidiffusion提示詞 → 寬幅全景圖片生成的未知區域是想像內容，並非還原真實 360° 場景
flux-klein參考圖片＋提示詞 → 新圖片大型 CPU 實驗；標準新版依賴無法在 Intel Mac 原生環境使用
ltx-video圖片＋提示詞 → 短影片大型 CPU 實驗；預設 9 影格預覽，不是即時影片服務
cogvideox圖片＋提示詞 → 影片大型 CPU 實驗；49 影格、720×480，運算與記憶體需求很高

在工作台展開「進階模型工作室」，按「檢查服務」；只有權重、相依套件與保守記憶體檢查通過的模型能啟動。執行期間一次只接受一個模型任務；可取消。新版有真正的模型呼叫程式，但接上介面不等於每個模型都完成實際生成測試，請查閱驗證頁。

4．GitHub：一支 SSH 腳本

您已有 SSH 金鑰，所以本流程不需要 PAT。已貼到對話或截圖中的 PAT 請到 GitHub Token 設定撤銷，不要放到程式或公開儲存庫。

cd "/你的解壓縮路徑/FRAME_AI_Studio"
bash Upload_FRAME_SSH.sh --dry-run
bash Upload_FRAME_SSH.sh --push

第一行比對內容並顯示計畫；第二行才上傳。SSH 若第一次連線，請依 GitHub 官方文件核對主機指紋。腳本保留目前遠端的 FRAME_AI_Studio/ 層級，更新根目錄入口導向此資料夾，不刪除其他檔案、不 force-push、不改您的來源資料。

模型分塊先依序送到暫存分支，所有資產齊全後才一次更新 main。中途斷線可重跑。既有瀏覽器模型依原 loader 的分塊與雜湊上傳；原生大型權重留在本機，不能把 Git LFS 指標當成可直接讀取的網頁模型。

GitHub 設定：Settings → Pages → main → /(root)。等待 Actions 的 Pages 部署成功後，開啟 網站首頁。腳本沒有替您在這次對話中推送到 GitHub。

5．語系、裝置與免費範圍

30 種介面語言依瀏覽器偏好自動選擇，也可手動切換；不是以 IP 或 Google Maps 判定國籍。新加入羅馬尼亞語、匈牙利語。介面語系不等於模型懂得該語言；內附神經配音仍以原有中文／英文聲庫為主，上游錯誤診斷可能使用英文。

桌機、筆電、手機、平板可開啟瀏覽器剪輯器；手機採較低輸出設定。大型模型服務只綁定該台電腦的 127.0.0.1，本版沒有手機連入另一台電腦的遠端生成服務。手機的 localhost 指手機自己。瀏覽器輸出 MP4／WebM 的可用性由實際瀏覽器與編碼器決定。

程式不需要付費 API。模型首次下載需要網路，之後仍消耗您自己的 CPU、磁碟與電力。模型與聲庫各有授權；「免費下載」不等於所有模型允許任意商業用途，尤其 LivePortrait 所依賴的人臉分析權重。
